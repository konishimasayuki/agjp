# A&G一括管理システム

株式会社A&G企画向けの、中国からの酒類輸入〜国内代理店への販売までを一括で管理するWebシステム（デモ版）です。

Next.js 15（App Router） / React 19 / Upstash Redis / Vercel / Resend（任意）

## 機能 

| メニュー | できること |
|---|---|
| 営業支援 | 代理店（デモは50社）を一覧で管理。進捗（見込み→商談中→提案・見積→取引中／休眠）、ランク、最終接触、次のアクションと期日、直近3か月の売上を表示。「今すぐ動く代理店」、リスト／ボード切替、活動履歴（訪問・電話・メール・試飲会・見積）の記録、45日以上注文がない取引先の警告。注文が入ると自動で「取引中」に |
| ダッシュボード | 今日やること（出荷待ち・未送信の発注書・入荷待ち・期限超過の請求など）、当月損益（売上−原価＝粗利−経費＝営業利益）、6か月推移 |
| 中国への発注 | 商品・ケース数・納品倉庫を選んで発注書を作成 → 中文/日本語併記の発注書（采购订单）を整形し、仕入先へメール送信。入荷登録で在庫に反映 |
| 在庫管理 | 入荷ごとに「ロット」で管理（仕入単価・為替・付帯費用/ケース・原価/ケース）。前回ロットとの原価差を▲▼表示。出荷は先入先出で原価計算。数量調整・履歴・CSV |
| 受注管理 | 代理店の注文フォーム／手入力で受注 → **請求書を自動作成**。出荷時にロット引当プレビューと粗利を表示。入金・キャンセル・CSV |
| 請求書 | 適格請求書の記載事項（登録番号・税率10%・税額）に対応。印刷/PDF保存・代理店へメール |
| 商品登録 | 写真（自動圧縮）・商品名・中文名・容量・ケース入数・度数・仕入単価(元)・販売単価・発注点・備考 |
| 経費 | 月別入力・科目別集計・推移グラフ・領収書写真・CSV |
| マスタ・設定 | 会社情報（請求書に反映）、仕入先・倉庫・代理店、為替・支払条件、JSONバックアップ、デモデータ初期化 |
| 注文フォーム（`/order`） | 代理店向けの公開ページ（取引中・休眠の代理店のみ選べます）。スマホで商品をケース単位で選んで送信 |

※ 関税・酒税・運賃などの付帯費用は経費ではなく、入荷時にケースごとに按分して在庫原価に含めています。

## 言語の切り替え
画面右上（PCは左メニューの下）の「日本語 / 中文」で、画面全体を日本語・中国語（簡体字）に切り替えられます。選んだ言語はその端末に保存されます。会社名・メモ・住所など、入力したデータは翻訳されません。請求書は日本の代理店宛てのため日本語のままです（発注書は中国語・日本語の併記）。

## デプロイ手順

### 1. GitHub
```bash
git init && git add . && git commit -m "init"
git branch -M main
git remote add origin https://github.com/<you>/ag-ikkatsu-system.git
git push -u origin main
```

### 2. Vercel
New Project → GitHub のリポジトリを Import → そのまま Deploy（設定変更不要）

### 3. Upstash（データ保存）
Vercel のプロジェクト → **Storage** → Upstash for Redis を作成して Connect。
`KV_REST_API_URL` / `KV_REST_API_TOKEN` が自動で入るので、Redeploy すれば完了です。
（Upstash 側で作った場合は `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` を手動で設定）

初回アクセス時にデモデータが自動投入されます。サイドバー下部が「Upstash に保存」になっていれば接続OK。
未接続のときはブラウザ内（localStorage）保存で動きます。

### 4. メール送信（任意・Resend）
| 環境変数 | 内容 |
|---|---|
| `RESEND_API_KEY` | Resend の API キー |
| `MAIL_FROM` | 送信元（例：`株式会社A&G企画 <order@your-domain.jp>`。Resend でドメイン認証が必要） |
| `MAIL_REPLY_TO` | 返信先（任意） |
| `MAIL_BCC` | 控えの送付先（任意） |

未設定でも「メールアプリで開く」で送信でき、そのあと「送信済みにする」で記録できます。

## 代理店への案内
受注管理画面の「注文フォームURL」をコピーして代理店へ共有してください（`https://<your-app>.vercel.app/order`）。

## ローカル開発
```bash
npm install
cp .env.example .env.local   # 必要なら値を入れる
npm run dev
```

## ⚠️ 本番運用の前に
- デモのため**ログインがありません**。`/api/db` は全データを返すため、本番では必ず認証（Basic認証・パスワード・Vercel のアクセス保護など）を追加してください。
- 注文フォームは代理店IDを選ぶだけなので、本番では代理店ごとのURLトークン等で本人確認を推奨します。
- データは Redis の `ag:` プレフィックスのキーに保存されます。定期的に「マスタ・設定 → バックアップ」でJSONを保存してください。

## 商品写真
デモ用に Wikimedia Commons の再利用可能な写真を `public/products/` に入れています（クレジットは `public/products/CREDITS.md` と商品登録画面の下）。実際の商品写真は、商品登録の「写真を選ぶ」で差し替えてください。
